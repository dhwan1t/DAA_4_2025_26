# Huffman Coding Web App

Live Demo: https://fe-ten-omega.vercel.app/
Backend API: https://huffman-project-yes.onrender.com

---

## About

This project implements the Huffman Coding algorithm for data compression using Java (Spring Boot) and provides a web-based interface to compress text.

---

## Features

* Convert text to binary (8-bit ASCII)
* Huffman compression
* Compression ratio calculation
* Code table visualization
* Full-stack deployment (frontend and backend)

---

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Java (Spring Boot)
* Deployment:

  * Frontend: Vercel
  * Backend: Render

---

## How to Use

1. Open the live demo link
2. Enter text
3. Click "Compress"
4. View compressed output and statistics

---

## Project Structure

* frontend/ → user interface (deployed on Vercel)
* src/ → backend logic (Spring Boot application)
